# Recipe Site（レシピサイト／トップページ） [3周目]

CODEJUMP 入門編の「レシピサイト／トップページ」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

「友達から趣味の料理レシピを公開するサイトを作ってほしいと頼まれた」という架空の案件設定のもと、トップページのWebページ（1ページ）を制作しています。

CODEJUMPの課題を通して、全幅表示のレイアウト設計、画面高さを生かしたメインビジュアル、フォント指定、レスポンシブ対応について学習しています。

## コーディング仕様・学習内容

- **フォント指定**: `Helvetica Neue`, `Arial`, `Hiragino Sans`, `Meiryo`, `sans-serif`
- **コンテンツ幅**: 全幅表示（100%）
- **メインビジュアル**: 全幅表示（高さはブラウザの画面高さに合わせる）
- **画像の横並び**:
  - 3枚の画像を均等配置して全幅表示
  - 高さ 500px 固定、画面サイズに応じて拡大・縮小
- **フッター**: SNSのリンクを横並びで中央配置
- **レスポンシブ対応**:
  - ブレークポイント 834px
  - スマホ表示時は 3枚の画像を縦並びに配置
- **Git / GitHub**: バージョン管理

## 使用技術

- HTML5
- CSS3
- Git / GitHub
